# A03 Group

This is the group of APIs between
the [Core's Consultant Service](../services/core/S01_Consultant_AI_Agent.md)
and [Core's Metrics Service](../services/core/S08_Core_Knowledge_Service.md).

This API consists of 1 API.

## A03a

This API is based on RabbitMQ

The API has **3** methods.

### A03a Method: `log_start_conversation`

Request body format:

{
  "method": "log_start_conversation",
  "params": {
    "conversation_id": "1001",
    "customer_id": "50023",
    "partner_name": "Viettel" (cái này có thể dùng partner_id),
    "created_at": "2025-12-08T15:21:00Z"

  },
  "id": "1234"
}

Response body format:

```json
{
    "id": "1234",
    "result": {
        "status": "success or error",
        "content": "the return value of the called method"
    }
}
```

On success, the content would be null.

On failure (`status == 'error'`), the content would
reflect what is going on. If the failure is
caused by some `Exception`, the content should
be `str(e)` with `e` being the `Exception` instance
that was the culprit.

In special error cases, the content must be "QUEUE_FULL" if the metric ingestion queue is at capacity (Cái này là optional nhé, cũng không rõ cần không)
