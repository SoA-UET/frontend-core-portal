# A32 Group

This is the group of APIs between
the [Partner's Local Knowledge Service](../services/partner/S11_Partner_Local_Knowledge_Service.md)
and [Partner's File Importing AI Agent](../services/partner/S15_File_Importing_AI_Agent.md).

**Direction:** S11 → S15

**Type:** Event (fire-and-forget, no response needed)

This API consists of 1 API.

## A32

This API is based on RabbitMQ.

The API has 1 event.

### A32 Event: `process_file_import`

This event is emitted by S11 to notify S15 that a file needs AI processing for knowledge extraction.

Event body format:

```json
{
  "event": "process_file_import",
  "data": {
    "update_id": "draft_upd_1234",
    "seaweed_file_id": "3,01234567"
  }
}
```

Supported file types:
- `"pdf"` - PDF documents

## Queue Configuration

- Event Queue: `file_import_events`

Configurable via `.env`:
- `FILE_IMPORT_EVENT_QUEUE`

## Notes

- S11 emits this event when receiving an update processing request from S12 (A33)
- S15 consumes the event, downloads file from SeaweedFS, AI extracts packages/FAQs
- After processing, S15 stores results back to S11 (via another API or direct DB access)
