# A32 Group

This is the group of APIs between
the [Partner's Local Knowledge Service](../services/partner/S11_Partner_Local_Knowledge_Service.md)
and [Partner's File Importing AI Agent](../services/partner/S15_File_Importing_AI_Agent.md).

This API consists of 1 API.

## A32

**Direction:** S11 → S15

This API is based on RabbitMQ .

The API has 1 method.

### A32 Method: `import_file`

This method is called by S11 to request that S15 process a file already uploaded to SeaweedFS and extract telecom knowledge.

Request body format (RPC request):

```json
{
  "method": "import_file",
  "params": {
    "seaweed_file_id": "3,01234567",
  },
  "id": "import_req_1234"
}
```

Supported file types: `.pdf`, `.xlsx`, `.xls`, `.docx`.

Response body format (RPC response) — S15 returns processed JSON changes back to S11:

```json
{
  "id": "import_req_1234",
  "result": {
    "status": "success",
    "content": {
      "processed_at": "2025-12-10T12:00:00Z",
      "packages": [ /* array of package objects */ ],
      "warnings": ["Row 15: missing service code"],
      "extracted_count": 42
    }
  }
}
```

On failure, `result.status` should be `error` and `result.content` contain an error message.

## Queue Configuration

- Request Queue: `file_import_requests`
- Response Queue: `file_import_responses`

Configurable via `.env`:
- `FILE_IMPORT_REQUEST_QUEUE`
- `FILE_IMPORT_RESPONSE_QUEUE`

## Notes

- `S11` calls `import_file` when it needs the AI agent to extract structured knowledge from a SeaweedFS file referenced by `seaweed_file_id`.
- `S15` should download the file, perform extraction, and return the structured JSON as the RPC response to S11.
- This RPC model is asynchronous. A response could come way later than when the request was accepted.
