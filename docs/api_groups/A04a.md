# A04 Group

This is the group of APIs between
the [Core's Customer Identity Service](../services/core/S04_Customer_Identity_Service.md)
and [Core's Metrics_Service](../services/core/S08_Core_Metrics_Service.md).


## A04a - Event

This API is based on RabbitMQ using queue: `s04_events_queue`

S04 publishes events to this queue, and S08 subscribes to update metrics in real-time.

The API has 1 event.

### A04a Event: `customer_registered`
Triggered when a new customer registers.

Event body format:
```json
{
  "event_type": "customer_registered",
  "params": {
    "customer_id": 50023,
    "partner_id": "abcdef"
  },
  "id": "001"
}
```
