# A34 Group

This is the group of APIs between
the [Partner's Knowledge Update Service](../services/partner/S12_Partner_Knowledge_Update_Service.md)
and [Core's Knowledge Validator Service](../services/core/S05_Knowledge_Validator_Service.md).

**Direction:** S12 (Partner) → S05 (Core)

**Type:** Event (fire-and-forget, no response needed)

This is a cross-system API that communicates over the Internet between Telcenter Partner and Telcenter Core systems.

This API consists of 1 API.

## A34

This API is based on RabbitMQ.

The API has 1 event.

### A34 Event: `submit_for_validation`

This event is emitted by S12 (Partner) to notify S05 (Core) that knowledge needs validation.

Event body format:

```json
{
  "event": "submit_for_validation",
  "data": {
    "partner_id": "viettel_partner_001",
    "submission_id": "partner_sub_1234",
    "seaweed_file_id": "3,01234567",
    "submitted_at": "2025-12-08T10:30:00Z"
  }
}
```

## Queue Configuration

- Event Queue: `core_validation_events`

Configurable via `.env`:
- `CORE_VALIDATION_EVENT_QUEUE`

## Notes

- S12 emits this event when Partner Portal submits an update to Core (H29 submit)
- S05 consumes the event, downloads JSON from SeaweedFS, validates
- After validation, S05 emits A08 event (if approved) for S03 to store
- Validation result is polled by S12 via H29 status endpoint
