# H22 Group

This is the group of HTTP APIs between the **Core Portal** and [Core's Knowledge Validator Service](../services/core/S05_Knowledge_Validator_Service.md).

This API consists of 1 API.

## Regarding HTTP API(s)

Endpoints denoted with "AUTH"
means that it must be authenticated
using JWT.

[How to verify JWTs](../auth/VERIFY.md)

## H22

**Direction:** Core Portal(Frontend) → S05

This API is based on HTTP (RESTful).

The API has 4 endpoints serving partner knowledge update management:
1.  View list of updates from partners
2.  View update details
3.  Approve update
4.  Reject update

### H22 Endpoint: `GET AUTH /api/v1/partner-updates`

This endpoint is called by Core Portal to retrieve the list of knowledge updates submitted by Telcenter Partners.

Request headers:
```
Authorization: Bearer <jwt_token>
```

Query parameters:
- `status` (optional): Filter by status - `pending`, `approved`, `rejected` (default: `pending`). If not specified, returns updates of all statuses.
- `partner_id` (optional): Filter by partner ID
- `pageNumber` (optional): Page number (default: 1)
- `pageSize` (optional): Items per page (default: 20, max: 100)

Response format (HTTP 200):

```json
{
  "status": "success",
  "total_count": 150,
  "page": 1,
  "limit": 20,
  "total_pages": 8,
  "updates": [
    {
      "id": string,
      "partner_id": "viettel_partner_001",
      "status": "pending",
      "validator_id": null,
      "created_at": "2025-12-08T10:30:00Z",
      "validated_at": null
    },

    {
      "id": string,
      "partner_id": "vinaphone_partner_001",
      "status": "approved",
      "validator_id": "abcdef", // core partner employee id deduced from JWT
      "created_at": "2025-12-07T09:15:00Z",
      "validated_at": "2025-12-07T10:00:00Z"
    },

    {
      "id": string,
      "partner_id": "mobifone_partner_001",
      "status": "rejected",
      "validator_id": "ghijkl", // core partner employee id deduced from JWT
      "created_at": "2025-12-06T14:20:00Z",
      "validated_at": "2025-12-06T15:00:00Z"
    }
  ],
  "summary": {
    "total": 150,
    "pending": 25,
    "approved": 100,
    "rejected": 25
  }
}
```

Note that items are sorted
by `created_at` descending (most recent first).

### H22 Endpoint: `POST AUTH /api/v1/partner-updates/{update_id}/approve`

This endpoint is called by Core Portal to approve a knowledge update from a partner after validation.

URL Parameters:

- `update_id`: The ID of the update to approve.

Request body format:

```json
{}
```

Response format (HTTP 200 OK):

```json
{
  "status": "success",
```

## Configuration

At the frontend code, base URL should be configurable via
environment variable:
- `KNOWLEDGE_VALIDATOR_SERVICE_URL` (e.g., `http://localhost:5005`)
