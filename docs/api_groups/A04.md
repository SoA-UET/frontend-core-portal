# A04 Group

This is the group of APIs between
the [Core's Customer Identity Service](../services/core/S04_Customer_Identity_Service.md)
and [Core's Metrics_Service](../services/core/S08_Metrics_Service.md).

## A04a - Event

This API is based on RabbitMQ using queue: `s04_events_queue`

S04 publishes events to this queue, and S08 subscribes to update metrics in real-time.

The API has 1 event.

### A04a Event: `customer_registered`

Triggered when a new customer registers.

Event body format:
```json
{
  "event_type": "customer_registered",
  "params": {
    "customer_id": "abcdefghi"
  },
  "id": "001"
}
```


# A04b Method
This API is based on RabbitMQ using queues:
- Request queue: `s08_s04_requests_queue`
- Response queue: `s08_s04_responses_queue`

S08 sends method requests to get aggregated metrics data from S04,
asynchronously.

The API has 1 method.

### A04b Method: `get_customers_count`

Request body format:

```json
{
  "method": "get_customers_count",
  "id": "002"
}
```

Response body format:

```json
{
    "id": "002",
    "result": {
        "status": "success or error",
        "content": ...
    }
}
```

On success, the content would be the total number of customers
currently saved in the database of S04. For example:

```json
{
    "id": "002",
    "result": {
        "status": "success",
        "content": 13550
    }
}
```

On failure (`status == 'error'`), the content would
reflect what is going on. If the failure is
caused by some `Exception`, the content should
be `str(e)` with `e` being the `Exception` instance
that was the culprit.
