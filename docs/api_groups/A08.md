# A08 Group

This is the group of APIs between
the [Core's Knowledge Validator Service](../services/core/S05_Knowledge_Validator_Service.md)
and [Core's Knowledge Service](../services/core/S03_Knowledge_Service.md).

**Direction:** S05 → S03

**Type:** Event (fire-and-forget, no response needed)

This API consists of 1 API.

## A08

This API is based on RabbitMQ.

The API has 1 event.

### A08 Event: `store_validated_knowledge`

This event is emitted by S05 to notify S03 that validated knowledge should be stored into the knowledge database.

Event body format:

```json
{
  "event": "store_validated_knowledge",
  "data": {
    "partner_id": "viettel_partner_001",
    "seaweed_file_id": "3,01234567",
    "validated_at": "2025-12-08T10:30:00Z"
  }
}
```

## Queue Configuration

- Event Queue: `knowledge_store_events`

Configurable via `.env`:
- `KNOWLEDGE_STORE_EVENT_QUEUE`

## Notes

- S05 emits this event after successful validation
- S03 consumes the event and downloads JSON from SeaweedFS to store in DB
- No response needed - S03 handles processing independently
- If duplicate detection fails, the content must be `"Duplicate detection error: <details>"`
- If database storage fails, the content must be `"Storage failed: <details>"`

## Queue Configuration

- Request Queue: `knowledge_validator_to_knowledge_requests`
- Response Queue: `knowledge_validator_to_knowledge_responses`

Both queues should be configurable via `.env` file with the following variables:
- `KNOWLEDGE_VALIDATOR_TO_KNOWLEDGE_REQUEST_QUEUE`
- `KNOWLEDGE_VALIDATOR_TO_KNOWLEDGE_RESPONSE_QUEUE`
