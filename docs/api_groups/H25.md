# H25 Group

This is the group of APIs between
the **Partner Portal**
and [Partner's General Information Service](../services/partner/S09_Partner_General_Information_Service.md).

This API consists of 1 API.

## H25 (TP-05: Cấu hình thông tin nhà mạng Partner)

This API is based on HTTP.

The API has 3 methods.

### H25 Method: `GET /api/partner/info`

Get current partner general information (name, logo, domain, etc.).

Request parameters: None (authenticated via session/token)

Response body format:

```json
{
    "status": "success",
    "data": {
        "partner_id": "partner_viettel",
        "partner_name": "Viettel Telecom",
        "partner_domain": "viettel.com.vn",
        "partner_logo_url": "https://cdn.example.com/logos/viettel.png",
        "contact_email": "support@viettel.com.vn",
        "contact_phone": "18008098",
        "address": "Số 1 Giang Văn Minh, Ba Đình, Hà Nội",
        "description": "Tập đoàn Công nghiệp - Viễn thông Quân đội",
        "updated_at": "2025-12-08T10:30:00Z"
    }
}
```

On failure:

```json
{
    "status": "error",
    "message": "Error description"
}
```

### H25 Method: `PUT /api/partner/info`

Update partner general information.

Request body format:

```json
{
    "partner_name": "Viettel Telecom",
    "partner_domain": "viettel.com.vn",
    "contact_email": "support@viettel.com.vn",
    "contact_phone": "18008098",
    "address": "Số 1 Giang Văn Minh, Ba Đình, Hà Nội",
    "description": "Tập đoàn Công nghiệp - Viễn thông Quân đội"
}
```

Response body format:

```json
{
    "status": "success",
    "message": "Partner information updated successfully",
    "data": {
        "partner_id": "partner_viettel",
        "partner_name": "Viettel Telecom",
        "partner_domain": "viettel.com.vn",
        "partner_logo_url": "https://cdn.example.com/logos/viettel.png",
        "contact_email": "support@viettel.com.vn",
        "contact_phone": "18008098",
        "address": "Số 1 Giang Văn Minh, Ba Đình, Hà Nội",
        "description": "Tập đoàn Công nghiệp - Viễn thông Quân đội",
        "updated_at": "2025-12-08T10:35:00Z"
    }
}
```

On failure (`status == 'error'`), the response would reflect what went wrong:

```json
{
    "status": "error",
    "message": "Invalid partner name format"
}
```

Special error cases:
- If the partner domain is already taken by another partner: `"Partner domain already exists"`
- If required fields are missing: `"Missing required fields: [field_names]"`
- If user is not authorized: `"Unauthorized: Admin privileges required"`

### H25 Method: `POST /api/partner/logo`

Upload new partner logo.

Request format: `multipart/form-data`

```
Content-Type: multipart/form-data
------WebKitFormBoundary
Content-Disposition: form-data; name="logo"; filename="logo.png"
Content-Type: image/png

[binary image data]
------WebKitFormBoundary--
```

Response body format:

```json
{
    "status": "success",
    "message": "Logo uploaded successfully",
    "data": {
        "logo_url": "https://cdn.example.com/logos/viettel_new.png",
        "uploaded_at": "2025-12-08T10:40:00Z"
    }
}
```

On failure (`status == 'error'`), the response would reflect what went wrong:

```json
{
    "status": "error",
    "message": "Error description"
}
```

Special error cases:
- If the file size exceeds limit (e.g., 5MB): `"File size too large. Maximum size is 5MB"`
- If the file format is not supported: `"Invalid file format. Supported formats: PNG, JPG, SVG"`
- If the file is corrupted or invalid: `"Invalid or corrupted image file"`
- If user is not authorized: `"Unauthorized: Admin privileges required"`
