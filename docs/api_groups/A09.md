# A09 Group

This is the group of APIs between
the [Partner's Authorized Partner Gateway Service](../services/partner/S16_Authorized_Partner_Gateway_Service.md)
and [Core's Partner Management Service](../services/core/S07_Partner_Management_Service.md).

This API consists of 2 API.

## A09a

This API is based on RabbitMQ.

The API has 1 methods.

### A09 Method: `get_partners`

**Purpose**: Return the list of partners

Request body format:

```json
{
  "method": "get_partners"
}
```

Response body format:

```json
{
  [
    {partner_id: "abc", "base_url": "https://partner-new.viettel.com.vn/api"},
    {partner_id: "efg", "base_url": "https://partner-new.vinaphone.com.vn/api"},
    ...
  ]
}
```

## A09b

This API is based on RabbitMQ.

The API has 3 events.

### A09 EVENT: `partner_create`

**Purpose**: Notify that a new partner has been created

Request body format:

```json
{
  "method": "partner_create",
  "params": {
    "partner_id": "partner_object_id",
    "name": "Viettel",
    "api_key": "generated_api_key",
    "base_url": "https://partner.viettel.com.vn/api"
  }
}
```

### A09 EVENT: `partner_update`

**Purpose**: Notify that a partner has been updated

Request body format:

```json
{
  "method": "partner_update",
  "params": {
    "partner_id": "partner_object_id",
    "name": "Viettel Updated",
    "api_key": "new_api_key",
    "base_url": "https://partner-new.viettel.com.vn/api"
  }
}
```

### A09 EVENT: `partner_delete`

**Purpose**: Notify that a partner has been deleted

Request body format:

```json
{
  "method": "partner_delete",
  "params": {
    "partner_id": "partner_object_id"
  }
}
```
