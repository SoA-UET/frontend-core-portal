# A09 Group

This is the group of APIs between
the [Core's Authorized Partner Gateway Service](../services/core/S16_Authorized_Partner_Gateway_Service.md)
and [Core's Partner Management Service](../services/core/S07_Partner_Management_Service.md).

This API consists of 2 API.

## A09a

**Direction:** S16 → S07

This API is based on RabbitMQ.

The API has 1 methods.

### A09a Method: `get_partners`

**Purpose**: Return the list of partners

Request body format:

```json
{
  "method": "get_partners",
  "id": "1234"
}
```

Response body format:

```json
{
  "id": "the corresponding request id",
  "result": {
    "status": "success or error",
    "content": "the return value of the called method"
  }
}
```

On success, the content would be:

```json
[
  { "partner_id": "abc", "base_url": "https://partner-new.viettel.com.vn/api" },
  { "partner_id": "efg", "base_url": "https://partner-new.vinaphone.com.vn/api" },
  ...
]
```

On failure (`status == 'error'`), the content would
reflect what is going on. If the failure is
caused by some `Exception`, the content should
be `str(e)` with `e` being the `Exception` instance
that was the culprit.

## A09b

**Direction:** S07 → S16

This API is based on RabbitMQ.

The API has 3 events.

### A09b EVENT: `partner_create`

**Purpose**: Notify that a new partner has been created

Message body format:

```json
{
  "event": "partner_create",
  "params": {
    "partner_id": "partner_object_id",
    "name": "Viettel",
    "api_key": "generated_api_key",
    "base_url": "https://partner.viettel.com.vn/api"
  }
}
```

### A09b EVENT: `partner_update`

**Purpose**: Notify that a partner has been updated

Message body format:

```json
{
  "event": "partner_update",
  "params": {
    "partner_id": "partner_object_id",
    "name": "Viettel Updated",
    "api_key": "new_api_key",
    "base_url": "https://partner-new.viettel.com.vn/api"
  }
}
```

### A09b EVENT: `partner_delete`

**Purpose**: Notify that a partner has been deleted

Message body format:

```json
{
  "event": "partner_delete",
  "params": {
    "partner_id": "partner_object_id"
  }
}
```
