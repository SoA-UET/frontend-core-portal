# A12 Group

This is the group of APIs between
the [Partner's General Information Service](../services/partner/S09_Partner_General_Information_Service.md)
and [Core's Authorized Core Gateway Service](../services/core/S17_Authorized_Core_Gateway_Service.md).

This API consists of 1 API.

## A12

This API is based on RabbitMQ.

The API has 3 methods.

### A12 Method: `get_core_service_endpoint`

**Purpose**: Query the endpoint URL of a specific Core service by name

Request body format:

```json
{
  "method": "get_core_service_endpoint",
  "params": {
    "service_identifier": "consultant"
  },
  "id": "1234"
}
```

The `service_identifier` can be service names like "consultant", "knowledge", "metrics", "portal", etc.

Response body format:

```json
{
    "id": "the corresponding request id",
    "result": {
        "status": "success or error",
        "content": "the return value of the called method"
    }
}
```

On success, the content would be:

```json
{
  "service_id": "uuid-string",
  "service_name": "consultant",
  "endpoint_url": "https://core.telcenter.vn/api/consultant",
  "api_version": "1.0.0",
  "status": "active",
  "last_health_check": "2025-12-08T10:30:00Z"
}
```

On failure (`status == 'error'`), the content would
reflect what is going on. If the failure is
caused by some `Exception`, the content should
be `str(e)` with `e` being the `Exception` instance
that was the culprit.

In special error cases, the content must be:
- `"Service not found"` if the service_identifier does not match any Core service
- `"Service unavailable"` if the service exists but is not currently available

### A12 Method: `get_core_main_endpoint`

**Purpose**: Query the main endpoint URL of the Core system

Request body format:

```json
{
  "method": "get_core_main_endpoint",
  "params": {},
  "id": "1235"
}
```

Response body format:

```json
{
    "id": "the corresponding request id",
    "result": {
        "status": "success or error",
        "content": "the return value of the called method"
    }
}
```

On success, the content would be:

```json
{
  "core_name": "Telcenter Core",
  "main_endpoint_url": "https://core.telcenter.vn/api",
  "gateway_url": "https://gateway.telcenter.vn",
  "api_version": "1.0.0",
  "status": "active",
  "supported_protocols": ["http", "https", "rabbitmq"],
  "last_health_check": "2025-12-08T10:30:00Z"
}
```

On failure (`status == 'error'`), the content would
reflect what is going on. If the failure is
caused by some `Exception`, the content should
be `str(e)` with `e` being the `Exception` instance
that was the culprit.

In special error cases, the content must be:
- `"Core unavailable"` if the Core system is not responding
- `"Gateway timeout"` if the gateway service does not respond within timeout

### A12 Method: `list_available_core_services`

**Purpose**: Get a list of all currently available Core services with their endpoints

Request body format:

```json
{
  "method": "list_available_core_services",
  "params": {},
  "id": "1236"
}
```

Response body format:

```json
{
    "id": "the corresponding request id",
    "result": {
        "status": "success or error",
        "content": "the return value of the called method"
    }
}
```

On success, the content would be:

```json
{
  "services": [
    {
      "service_id": "uuid-string-1",
      "service_name": "consultant",
      "endpoint_url": "https://core.telcenter.vn/api/consultant",
      "status": "active"
    },
    {
      "service_id": "uuid-string-2",
      "service_name": "knowledge",
      "endpoint_url": "https://core.telcenter.vn/api/knowledge",
      "status": "active"
    },
    {
      "service_id": "uuid-string-3",
      "service_name": "metrics",
      "endpoint_url": "https://core.telcenter.vn/api/metrics",
      "status": "active"
    },
    {
      "service_id": "uuid-string-4",
      "service_name": "employee_identity",
      "endpoint_url": "https://core.telcenter.vn/api/employee",
      "status": "active"
    }
  ],
  "total_count": 4,
  "timestamp": "2025-12-08T10:30:00Z"
}
```

On failure (`status == 'error'`), the content would
reflect what is going on. If the failure is
caused by some `Exception`, the content should
be `str(e)` with `e` being the `Exception` instance
that was the culprit.

In special error cases, the content must be:
- `"No services available"` if there are no Core services currently available
- `"Gateway connection error"` if unable to connect to the Core gateway
- `"Authentication required"` if the partner is not authorized to query Core services
