# A12 Group

This is the group of APIs between
the [Partner's General Information Service](../services/partner/S09_Partner_General_Information_Service.md)
and [Partner's Authorized Core Gateway Service](../services/core/S17_Authozied_Core_Gateway_Service.md).

This API consists of 2 API.

## A12a

This API is based on RabbitMQ.

The API has 1 methods.

### A12 Method: `get_core_info`

**Purpose**: Query the Core connection information (API URL, Partner ID and API key) for internal Partner services

Request body format:

```json
{
  "method": "get_core_info",
  "id": "1234"
}
```

Response body format:

```json
{
  "status": "success",
  "result": {
    "partner_id": "abc123",
    "api_key": "partner_api_key",
    "core_url": "https://core.telcenter.com.vn/api"
  },
  "id": "the corresponding request id"
}
```

## A12b

This API is based on RabbitMQ.

The API has 1 event.

### A12 EVENT: `core_update`

**Purpose**: Notify that the Core connection information has been updated

Message body format:

```json
{
  "event": "core_update",
  "params": {
    "partner_id": "abc123",
    "name": "Viettel",
    "api_key": "new_api_key",
    "core_url": "https://core-new.telcenter.com.vn/api"
  }
}
```
