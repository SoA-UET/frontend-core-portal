# A17 Group

This is the group of APIs between
the [Core's Metrics Service](../services/core/S08_Metrics_Service.md)
and [Partner's Metrics Service](../services/partner/S14_Partner_Metrics_Service.md).


## A17a - Events API

This API is based on RabbitMQ using queue: `s08_events_queue`

In this API, S08 publishes events to this queue, and S14 subscribes to update partner-specific metrics in real-time.

The API has 3 event types.

### A17a Event: `conversation_start_by_partner`

Triggered when a new conversation starts for a specific partner.

Event body format:

```json
{
  "event_type": "conversation_start_by_partner",
  "params": {
    "conversation_id": "1001",
    "partner_id": "abcdef",
    "started_at": "2025-12-13T14:30:00Z"
  },
  "id": "1234"
}
```

**Metrics Impact on S14:**
- Increment total_conversations for this partner: +1 

### A17a Event: `conversation_changed_status_by_partner`

Triggered when a conversation status changes for a specific partner (e.g., from FORWARDING to text, from text to calling, etc.).

Event body format:

```json
{
  "event_type": "conversation_changed_status_by_partner",
  "params": {
    "conversation_id": "1001",
    "partner_id": "abcdef",
    "old_status": "FORWARDING",
    "new_status": "HUMAN_AGENT_TEXTING",
    "updated_at": "2025-12-13T14:35:00Z"
  },
  "id": "1235"
}
```

**Possible status values:**
- `FORWARDING`: Conversation being forwarded to partner
- `HUMAN_AGENT_TEXTING`: Partner consultant handling via text
- `HUMAN_AGENT_CALLING`: Partner consultant handling via calling


### A17a Event: `conversation_satisfaction_change_by_partner`

Triggered when customer satisfaction rating changes for a conversation of a specific partner.

Event body format:

```json
{
  "event_type": "conversation_satisfaction_change_by_partner",
  "params": {
    "conversation_id": "1001",
    "partner_id": "abcdef",
    "old_satisfaction": 1,
    "new_satisfaction": 5,
    "updated_at": "2025-12-13T15:50:00Z"
  },
  "id": "1236"
}
```

**Satisfaction values:** 1, 2, 3, 4, 5
