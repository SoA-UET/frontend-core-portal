# H11 Group

This is the group of APIs between
the [Core's Partner Management Service](../services/core/S07_Partner_Management_Service.md)
and [Partner's General Information Service](../services/partner/S09_Partner_General_Information_Service.md).

This API consists of 1 API.

## H11

This API is based on HTTP.

The API has 2 endpoints.

### H11 Endpoint: `GET /api/v1/partners/:id`

**Purpose**: Retrieve detailed information about a specific partner

Request parameters: `:id` in URL path (partner_id)

Response body format:

```json
{
  "status": "success",
  "data": {
    "partner_id": "abc",
    "name": "Viettel",
    "base_url": "https://partner-new.viettel.com.vn/api",
    "created_at": "2025-12-08T11:00:00Z",
    "updated_at": "2025-12-08T11:00:00Z"
  }
}
```

On failure:

```json
{
  "status": "error",
  "message": "Error description"
}
```

### H11 Endpoint: `POST /api/v1/partners/:id/verify-connection`

**Purpose**: Verify the Core connection.

Request parameters: `:id` in URL path (partner_id)

Request headers: include API key:

  Authorization: Bearer <API_key>

Request body format: Empty or `{}`

Response body format:

```json
{
  "status": "success",
  "data": {
    "partner_id": "uuid-string",
  }
}
```

On failure:

```json
{
  "status": "error",
  "message": "Error description"
}
```
