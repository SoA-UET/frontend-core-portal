# H11 Group

This is the group of APIs between
the [Core's Partner Management Service](../services/core/S07_Partner_Management_Service.md)
and [Partner's General Information Service](../services/partner/S09_Partner_General_Information_Service.md).

This API consists of 1 API.

## H11

This API is based on HTTP.

The API has 3 endpoints.

### H11 Endpoint: `GET /api/v1/partners/:id`

**Purpose**: Retrieve detailed information about a specific partner

Request parameters: `:id` in URL path (partner_id)

Response body format:

```json
{
  "status": "success",
  "data": {
    "partner_id": "uuid-string",
    "partner_name": "Viettel",
    "partner_url": "https://partner.viettel.com.vn/api",
    "status": "active",
    "capabilities": ["voice", "sms", "data"],
    "max_concurrent_sessions": 100,
    "current_active_sessions": 15,
    "last_health_check": "2025-12-08T10:30:00Z",
    "health_status": "healthy"
  }
}
```

On failure:

```json
{
  "status": "error",
  "message": "Error description"
}
```

Special error cases:
- If the partner_id does not exist in the system: `"Partner not found"`
- If the partner's service cannot be reached: `"Partner service unavailable"`

### H11 Endpoint: `POST /api/v1/partners/:id/verify-connection`

**Purpose**: Verify the Core connection.

Request parameters: `:id` in URL path (partner_id)

Request headers: include API key:

  Authorization: Bearer <API_key>

Request body format: Empty or `{}`

Response body format:

```json
{
  "status": "success",
  "data": {
    "partner_id": "uuid-string",
    "connection_status": "active",
    "response_time_ms": 45,
    "last_successful_ping": "2025-12-08T10:30:00Z",
    "api_version": "1.0.0"
  }
}
```

On failure:

```json
{
  "status": "error",
  "message": "Error description"
}
```

Special error cases:
- If the partner_id does not exist: `"Partner not found"`
- If the partner service does not respond within the timeout period: `"Connection timeout"`
- If the API key is invalid or expired: `"Authentication failed"`
