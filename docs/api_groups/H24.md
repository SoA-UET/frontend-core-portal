# H24 Group

This is the group of APIs between
the Core Portal (Frontend)
and [Core's Partner Management Service](../services/core/S07_Partner_Management_Service.md).

This API consists of 1 API.

## H24

This API is based on HTTP.

The API has 3 endpoints.

### H24 Endpoint: `POST /api/v1/partners`

**Purpose**: Create a new Telcenter Partner connection (TC-03.1)

Request body format:

```json
{
  "partner_name": "Viettel",
  "partner_url": "https://partner.viettel.com.vn/api"
}
```

Response body format:

```json
{
  "status": "success",
  "data": {
    "partner_id": "uuid-string",
    "partner_name": "Viettel",
    "partner_url": "https://partner.viettel.com.vn/api",
    "api_key": "generated-api-key",
    "created_at": "2025-12-08T10:30:00Z",
    "status": "active"
  }
}
```

On failure:

```json
{
  "status": "error",
  "message": "Error description"
}
```

Special error cases:

- If the API key is wrong: `"Invalid API key"`
- If the connection test to the partner URL fails: `"Partner URL unreachable"`
- If a partner with the same name or URL already exists: `"Partner already exists"`

### H24 Endpoint: `PATCH /api/v1/partners/:id`

**Purpose**: Update an existing Telcenter Partner connection (TC-03.2)

Request body format (all fields optional):

```json
{
  "name": "Viettel Updated",
  "api_key": "xxx",
  "base_url": "https://partner-new.viettel.com.vn/api"
}
```

Response body format:

```json
{
  "status": "success",
  "data": {
    "name": "Viettel Updated",
    "api_key": "xxx",
    "base_url": "https://partner-new.viettel.com.vn/api",
    "created_at": "2025-12-08T11:00:00Z",
    "updated_at": "2025-12-08T11:00:00Z"
  }
}
```

On failure:

```json
{
  "status": "error",
  "message": "Error description"
}
```

### H24 Endpoint: `DELETE /api/v1/partners/:id`

**Purpose**: Delete an existing Telcenter Partner connection (TC-03.3)

Request parameters: `:id` in URL path (partner_id)

Response body format:

```json
{
  "status": "success"
}
```

On failure:

```json
{
  "status": "error",
  "message": "Error description"
}
```
