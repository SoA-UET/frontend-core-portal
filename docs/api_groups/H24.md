# H24 Group

This is the group of APIs between
the Core Portal (Frontend)
and [Core's Partner Management Service](../services/core/S07_Partner_Management_Service.md).

This API consists of 1 API.

## Regarding HTTP API(s)

Endpoints denoted with "AUTH"
means that it must be authenticated
using JWT.

[How to verify JWTs](../auth/VERIFY.md)

## H24

**Direction:** Core Portal (Frontend) → S07

This API is based on HTTP.

The API has 3 endpoints.

### H24 Endpoint: `GET AUTH /api/v1/partners`

**Purpose**: Retrieve the list of Telcenter Partner connections.

Response body format:

```json
{
  "status": "success",
  "data": [
    {
      "id": "...",
      "name": "Viettel",
      "base_url": "https://partner.viettel.com.vn/api",
      "created_at": "2025-12-08T10:30:00Z",
      "updated_at": "active",
      "api_key": "..."
    },
    ...
  ]
}
```

### H24 Endpoint: `POST AUTH /api/v1/partners`

**Purpose**: Create a new Telcenter Partner connection (TC-03.1)

Request body format:

```json
{
  "name": "Viettel",
  "base_url": "https://partner.viettel.com.vn/api"
}
```

Response body format:

```json
{
  "status": "success",
  "data": {
    "id": "...",
    "name": "Viettel",
    "base_url": "https://partner.viettel.com.vn/api",
    "api_key": "generated-api-key",
    "created_at": "2025-12-08T10:30:00Z",
    "updated_at": "2025-12-08T10:30:00Z"
  }
}
```

On failure:

```json
{
  "status": "error",
  "message": "Error description"
}
```

Special error cases:

- If a partner with the same name or URL already exists: `"Partner already exists"`

### H24 Endpoint: `PATCH AUTH /api/v1/partners/:id`

**Purpose**: Update an existing Telcenter Partner connection (TC-03.2)

Request body format (all fields optional):

```json
{
  "name": "Viettel Updated",
  "api_key": "xxx",
  "base_url": "https://partner-new.viettel.com.vn/api"
}
```

Response body format:

```json
{
  "status": "success",
  "data": {
    "id": "...",
    "name": "Viettel",
    "base_url": "https://partner.viettel.com.vn/api",
    "api_key": "generated-api-key",
    "created_at": "2025-12-08T10:30:00Z",
    "updated_at": "2025-12-08T10:30:00Z"

  }
}
```

On failure:

```json
{
  "status": "error",
  "message": "Error description"
}
```

### H24 Endpoint: `DELETE AUTH /api/v1/partners/:id`

**Purpose**: Delete an existing Telcenter Partner connection (TC-03.3)

Request parameters: `:id` in URL path (partner_id)

Response body format:

```json
{
  "status": "success"
}
```

On failure:

```json
{
  "status": "error",
  "message": "Error description"
}
```
