# H24 Group

This is the group of APIs between
the Core Portal (Frontend)
and [Core's Partner Management Service](../services/core/S07_Partner_Management_Service.md).

This API consists of 1 API.

## H24

This API is based on HTTP.

The API has 3 methods.

### H24 Method: `create_partner`

**Purpose**: Create a new Telcenter Partner connection (TC-03.1)

Request body format:

```json
{
  "method": "create_partner",
  "params": {
    "partner_name": "Viettel",
    "partner_url": "https://partner.viettel.com.vn/api",
    "otp": "123456"
  },
  "id": "1234"
}
```

Response body format:

```json
{
    "id": "the corresponding request id",
    "result": {
        "status": "success or error",
        "content": "the return value of the called method"
    }
}
```

On success, the content would be the newly created partner information:

```json
{
  "partner_id": "uuid-string",
  "partner_name": "Viettel",
  "partner_url": "https://partner.viettel.com.vn/api",
  "api_key": "generated-api-key",
  "created_at": "2025-12-08T10:30:00Z",
  "status": "active"
}
```

On failure (`status == 'error'`), the content would
reflect what is going on. If the failure is
caused by some `Exception`, the content should
be `str(e)` with `e` being the `Exception` instance
that was the culprit.

In special error cases, the content must be:
- `"Invalid OTP"` if the OTP verification fails
- `"Partner URL unreachable"` if the connection test to the partner URL fails
- `"Partner already exists"` if a partner with the same name or URL already exists

### H24 Method: `update_partner`

**Purpose**: Update an existing Telcenter Partner connection (TC-03.2)

Request body format:

```json
{
  "method": "update_partner",
  "params": {
    "partner_id": "uuid-string",
    "partner_name": "Viettel Updated",
    "partner_url": "https://partner-new.viettel.com.vn/api"
  },
  "id": "1235"
}
```

Response body format:

```json
{
    "id": "the corresponding request id",
    "result": {
        "status": "success or error",
        "content": "the return value of the called method"
    }
}
```

On success, the content would be the updated partner information:

```json
{
  "partner_id": "uuid-string",
  "partner_name": "Viettel Updated",
  "partner_url": "https://partner-new.viettel.com.vn/api",
  "api_key": "existing-api-key",
  "updated_at": "2025-12-08T11:00:00Z",
  "status": "active"
}
```

On failure (`status == 'error'`), the content would
reflect what is going on. If the failure is
caused by some `Exception`, the content should
be `str(e)` with `e` being the `Exception` instance
that was the culprit.

In special error cases, the content must be:
- `"Partner not found"` if the partner_id does not exist
- `"Partner URL unreachable"` if the connection test to the new partner URL fails

### H24 Method: `delete_partner`

**Purpose**: Delete an existing Telcenter Partner connection (TC-03.3)

Request body format:

```json
{
  "method": "delete_partner",
  "params": {
    "partner_id": "uuid-string"
  },
  "id": "1236"
}
```

Response body format:

```json
{
    "id": "the corresponding request id",
    "result": {
        "status": "success or error",
        "content": "the return value of the called method"
    }
}
```

On success, the content would simply be:

```json
{
  "partner_id": "uuid-string",
  "deleted_at": "2025-12-08T12:00:00Z",
  "message": "Partner connection deleted successfully"
}
```

On failure (`status == 'error'`), the content would
reflect what is going on. If the failure is
caused by some `Exception`, the content should
be `str(e)` with `e` being the `Exception` instance
that was the culprit.

In special error cases, the content must be:
- `"Partner not found"` if the partner_id does not exist
- `"Cannot delete active partner with ongoing sessions"` if there are active sessions using this partner
