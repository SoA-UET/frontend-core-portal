# H26 Group

This is the group of APIs between
the **Partner Portal**
and [Partner's General Information Service](../services/partner/S09_Partner_General_Information_Service.md).

This API consists of 1 API.

## Regarding HTTP API(s)

Endpoints denoted with "AUTH"
means that it must be authenticated
using JWT.

[How to verify JWTs](../auth/VERIFY.md)

## H26

**Direction:** the Partner Portal (Frontend) → S09

This API is based on HTTP.

The API has 1 endpoints.

### H26 Endpoint: `POST AUTH /api/partner/core-connection/test`

Test the connection to Telcenter Core with saved credentials.

Request body format:

```json
{
    "core_url": "https://core.telcenter.vn",
    "api_key": "abcdefghijklmno"
}
```

Response body format:

```json
{
    "status": "success",
    "message": {
        "partner_id": "0a1b2c3d4e"
    }
}
```

On failure (`status == 'error'`), the response would reflect what went wrong:

```json
{
    "status": "error",
    "message": "Error description"
}
```

**NOTE:** this API won't save the connection information; it only tests the connection.
The frontend should call H25 API to save the information.
