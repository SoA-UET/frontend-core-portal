# H26 Group

This is the group of APIs between
the **Partner Portal**
and [Partner's General Information Service](../services/partner/S09_Partner_General_Information_Service.md).

This API consists of 1 API.

## H26 (TP-06: Thiết lập / cập nhật kết nối đến Telcenter Core)

This API is based on HTTP.

The API has 3 methods.

### H26 Method: `GET /api/partner/core-connection`

Get current Telcenter Core connection configuration.

Request parameters: None (authenticated via session/token)

Response body format:

```json
{
    "status": "success",
    "data": {
        "core_url": "https://core.telcenter.vn",
        "api_key": "pk_live_51J3K4L5M6N7O8P9Q0R1S2T3U4V5W6X7Y8Z9",
        "connection_status": "active",
        "last_tested_at": "2025-12-08T10:30:00Z",
        "last_test_result": "success",
        "created_at": "2025-11-01T08:00:00Z",
        "updated_at": "2025-12-08T10:30:00Z"
    }
}
```

On failure:

```json
{
    "status": "error",
    "message": "Error description"
}
```

Special error cases:
- If no connection is configured yet: `"No core connection configured"`
- If user is not authorized: `"Unauthorized: Admin privileges required"`

### H26 Method: `POST /api/partner/core-connection/test`

Test the connection to Telcenter Core with provided credentials.

Request body format:

```json
{
    "core_url": "https://core.telcenter.vn",
    "api_key": "pk_live_51J3K4L5M6N7O8P9Q0R1S2T3U4V5W6X7Y8Z9"
}
```

Response body format:

```json
{
    "status": "success",
    "message": "Connection test successful",
    "data": {
        "connection_status": "active",
        "response_time_ms": 145,
        "core_version": "1.2.3",
        "tested_at": "2025-12-08T10:35:00Z"
    }
}
```

On failure (`status == 'error'`), the response would reflect what went wrong:

```json
{
    "status": "error",
    "message": "Connection test failed",
    "data": {
        "connection_status": "failed",
        "error_details": "Connection timeout after 30 seconds",
        "tested_at": "2025-12-08T10:35:00Z"
    }
}
```

Special error cases:
- If the Core URL is invalid or unreachable: `"Cannot connect to Core: Invalid URL or server unreachable"`
- If the API key is invalid: `"Authentication failed: Invalid API key"`
- If the API key is expired: `"Authentication failed: API key has expired"`
- If the Core server returns an error: `"Core server error: [error details]"`
- If network timeout occurs: `"Connection timeout after 30 seconds"`
- If user is not authorized: `"Unauthorized: Admin privileges required"`

### H26 Method: `PUT /api/partner/core-connection`

Save or update the Telcenter Core connection configuration.

Request body format:

```json
{
    "core_url": "https://core.telcenter.vn",
    "api_key": "pk_live_51J3K4L5M6N7O8P9Q0R1S2T3U4V5W6X7Y8Z9"
}
```

Response body format:

```json
{
    "status": "success",
    "message": "Core connection configuration saved successfully",
    "data": {
        "core_url": "https://core.telcenter.vn",
        "api_key": "pk_live_51J3K4L5M6N7O8P9Q0R1S2T3U4V5W6X7Y8Z9",
        "connection_status": "active",
        "updated_at": "2025-12-08T10:40:00Z"
    }
}
```

On failure (`status == 'error'`), the response would reflect what went wrong:

```json
{
    "status": "error",
    "message": "Error description"
}
```

Special error cases:
- If required fields are missing: `"Missing required fields: [field_names]"`
- If the Core URL format is invalid: `"Invalid Core URL format"`
- If the API key format is invalid: `"Invalid API key format"`
- If the connection was not tested successfully first: `"Cannot save: Connection test must be successful before saving"`
- If user is not authorized: `"Unauthorized: Admin privileges required"`

**Note**: According to the use case flow (TP-06), the system should only allow saving the configuration if the connection test was successful. The frontend should enforce this by requiring a successful test before enabling the save button. The backend should also validate that a recent successful test was performed before accepting the save request.
