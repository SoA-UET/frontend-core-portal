# H21 Group

This is the group of HTTP APIs between
the **Core Portal**
and [Core's Metrics Service](../services/core/S08_Metrics_Service.md).

This API consists of 5 endpoints.

## Regarding HTTP API(s)

Endpoints denoted with "AUTH"
means that it must be authenticated
using JWT.

[How to verify JWTs](../auth/VERIFY.md)

## H21

This API is based on HTTP (RESTful).

The API has 5 endpoints serving metrics data:
1. Total number of users
2. Total number of conversations (overall, texting conversations, calling conversations)
3. Distribution of consultation sessions by customer satisfaction rating (1-5 stars)
4. Rate of offloaded consultation sessions (successfully handled by AI agents)
5. Rate of offloaded consultation sessions by partner

### H21.1 Endpoint: `GET AUTH /api/v1/metrics/users/total`

This endpoint is called by Core Portal to retrieve the total number of users registered in the system.

Request headers:
```
Authorization: Bearer <jwt_token>
```

Query parameters:
- `from_date` (optional): Start date for counting users (ISO 8601 format)
- `to_date` (optional): End date for counting users (ISO 8601 format)

Response format (HTTP 200):

```json
{
  "status": "success",
  "total_customers": 15420,
  "from_date": "2025-01-01T00:00:00Z",
  "to_date": "2025-12-12T23:59:59Z"
}
```

### H21.2 Endpoint: `GET AUTH /api/v1/core/metrics/conversations/summary`

This endpoint is called by Core Portal to retrieve conversation statistics including total, texting, and calling conversations.

Request headers:
```
Authorization: Bearer <jwt_token>
```

Query parameters:
- `from_date` (optional): Start date for conversation statistics (ISO 8601 format)
- `to_date` (optional): End date for conversation statistics (ISO 8601 format)

Response format (HTTP 200):

```json
{
  "status": "success",
  "total_conversations": 45320,
  "texting_conversations": 38450,
  "calling_conversations": 6870,
  "from_date": "2025-01-01T00:00:00Z",
  "to_date": "2025-12-12T23:59:59Z"
}
```

### H21.3 Endpoint: `GET AUTH /api/v1/core/metrics/consultations/satisfaction`

This endpoint is called by Core Portal to retrieve the distribution of consultation sessions by customer satisfaction rating (1-5 stars).

Request headers:
```
Authorization: Bearer <jwt_token>
```

Query parameters:
- `from_date` (optional): Start date for consultation statistics (ISO 8601 format)

```json
{
  "status": "success",
  "total_conversations": 1000,
  "satisfaction_distribution": {
        "satisfaction_1": 10,
        "satisfaction_2": 25,
        "satisfaction_3": 150,
        "satisfaction_4": 400,
        "satisfaction_5": 415
  },
  "average_rating": 4.19,
  "from_date": "2025-01-01T00:00:00Z",
  "to_date": "2025-12-12T23:59:59Z"
}
```

### H21.4 Endpoint: `GET AUTH /api/v1/core/metrics/consultations/offload-rate`

This endpoint is called by Core Portal to retrieve the rate of consultation sessions that were successfully offloaded (handled by AI agents without human intervention).

Request headers:
```
Authorization: Bearer <jwt_token>
```

Query parameters:
- `from_date` (optional): Start date for consultation statistics (ISO 8601 format)
- `to_date` (optional): End date for consultation statistics (ISO 8601 format)

Response format (HTTP 200):

```json
{
  "status": "success",
  "total_conversations": 38420,
  "ai_failed_conversation": 9770,
  "offloaded_conversations": 28650,
  "offload_rate_percentage": 74.57,
  "from_date": "2025-01-01T00:00:00Z",
  "to_date": "2025-12-12T23:59:59Z"
}
```

### H21.5 Endpoint: `GET AUTH /api/v1/core/metrics/consultations/offload-rate-by-partner`

This endpoint is called by Core Portal to retrieve the rate of offloaded consultation sessions broken down by partner.

Request headers:
```
Authorization: Bearer <jwt_token>
```

Query parameters:
- `from_date` (optional): Start date for consultation statistics (ISO 8601 format)
- `to_date` (optional): End date for consultation statistics (ISO 8601 format)
- `partner_id` (optional): Filter by specific partner ID

Response format (HTTP 200):

```json
{
  "status": "success",
  "total_consultations": 38420,
  "partners": [
    {
      "partner_id": "abcdef",
      "partner_name": "Viettel",
      "total_conversations": 18650,
      "offloaded_conversations": 14120,
      "ai_failed_conversations": 4530,
      "offload_rate_percentage": 75.71
    },
    {
      "partner_id": "ghiklm",
      "partner_name": "Vietnamobile",
      "total_conversations": 12840,
      "offloaded_conversations": 9480,
      "ai_failed_conversations": 3360,
      "offload_rate_percentage": 73.83
    },
    {
      "partner_id": "opqrst",
      "partner_name": "MobiFone",
      "total_conversations": 6930,
      "offloaded_conversations": 5050,
      "ai_failed_conversations": 1880,
      "offload_rate_percentage": 72.87
    }
  ],
  "overall_offload_rate_percentage": 74.57,
  "from_date": "2025-01-01T00:00:00Z",
  "to_date": "2025-12-12T23:59:59Z"
}
```

**Field descriptions for partner objects:**
- `partner_id`: Unique identifier for the partner
- `partner_name`: Display name of the partner (fetched from S07 via A07 API). If S07 is unavailable, this field may be omitted or equal to `partner_id`
- `total_conversations`: Total number of conversations handled by this partner
- `offloaded_conversations`: Number of conversations successfully handled by AI without human intervention
- `ai_failed_conversations`: Number of conversations that required human intervention
- `offload_rate_percentage`: Percentage of conversations successfully offloaded (= offloaded / total × 100)

## Error Responses

The following error responses apply to all endpoints:

**HTTP 400 Bad Request**
```json
{
  "status": "error",
  "error_code": "INVALID_PARAMETERS",
  "message": "Invalid query parameters",
  "details": "from_date must be before to_date"
}
```

**HTTP 401 Unauthorized**
```json
{
  "status": "error",
  "error_code": "UNAUTHORIZED",
  "message": "Authentication token is invalid or expired"
}
```

**HTTP 403 Forbidden**
```json
{
  "status": "error",
  "error_code": "FORBIDDEN",
  "message": "User does not have permission to view metrics"
}
```

**HTTP 500 Internal Server Error**
```json
{
  "status": "error",
  "error_code": "INTERNAL_ERROR",
  "message": "An internal server error occurred while retrieving metrics"
}
```

## Configuration

Base API URL (for frontend) should be configurable via `.env`:
- `CORE_METRICS_SERVICE_URL` (e.g., `http://localhost:5008`)
