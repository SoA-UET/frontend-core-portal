# A05 Group

This is the group of APIs between
the [Core's Knowledge Validator Service](../services/core/S05_Knowledge_Validator_Service.md)
and [Core's Metrics Service](../services/core/S08_Core_Knowledge_Service.md).

This API consists of 1 API.

## A05a

This API is based on RabbitMQ

The API has 2 methods.

### A03a Method: `log_submission_received`

Request body format:

{
  "method": "log_submission_received",
  "params": {
    "employee_id": 8801,
    "partner_name": "Viettel"
  },
  "id": "1234"
}

Response body format:

```json
{
    "id": "1234",
    "result": {
        "status": "success or error",
        "content": "the return value of the called method"
    }
}
```

On success, the content would be null.

On failure (`status == 'error'`), the content would
reflect what is going on. If the failure is
caused by some `Exception`, the content should
be `str(e)` with `e` being the `Exception` instance
that was the culprit.
