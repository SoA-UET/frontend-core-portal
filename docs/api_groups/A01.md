# A01 Group

This is the group of APIs between
the [Core's Consultant AI Agent](../services/core/S02_Consultant_AI_Agent.md)
and [Core's Knowledge Service](../services/core/S03_Knowledge_Service.md).

This API consists of 1 API.

## A01

This API is based on RabbitMQ.

Direction: from S02 to S03.

The API has 2 methods.

### A01 Method: `update_dataframe`

S02 calls this method to
update the packages' data (NOT FAQs)
for S03 to use in its knowledge base
for answering users' queries.

        "4G tốc độ cao/chu kỳ": 0,
        "Gọi nội mạng": "",
        "Gọi ngoại mạng": "",
        "Tin nhắn": "",
        "Chi tiết": "",
        "Tự động gia hạn": "Có",
        "Cú pháp đăng ký": "SD70 DK8 gửi 290"

Response body format:

```json
{
    "id": "the corresponding request id",
    "result": {

        "content": "the return value of the called method"
    }

```

On success, the content would simply be `OK`. No
more information is provided.

On failure (`status == 'error'`), the content would
reflect what is going on. If the failure is
caused by some `Exception`, the content should
be `str(e)` with `e` being the `Exception` instance
that was the culprit.

### A01 Method: `update_faqs`

S02 calls this method to
update the FAQs for S03 to use
in its knowledge base for answering users' queries.

Request body format:

```json
{
  "method": "update_faqs",
  "params": {
    "source": "Viettel",
    "faqs": [
      {
        "question": "Làm thế nào để đăng ký gói cước SD70?",
        "answer": "Để đăng ký gói cước SD70, soạn tin nhắn với cú pháp 'SD70 DK8 gửi 290' từ số điện thoại của bạn."
      },
      {
        "question": "Gói V90B có ưu đãi gì cho cuộc gọi nội mạng?",
        "answer": "Gói V90B miễn phí các cuộc gọi nội mạng dưới 10 phút và cung cấp 30 phút gọi ngoại mạng miễn phí."
      }
      // ... more if needed
    ]
  },
  "id": "5678"
}
```

Response body format:

```json
{
    "id": "the corresponding request id",
    "result": {
        "status": "success or error",
        "content": "the return value of the called method"
    }
}
```

On success, the content would simply be `OK`. No
more information is provided.

On failure (`status == 'error'`), the content would
reflect what is going on. If the failure is
caused by some `Exception`, the content should
be `str(e)` with `e` being the `Exception` instance
that was the culprit.

## Notes

S03 is not supposed to wait for any response
from S02 after sending the requests.

## Queue Configuration

- Requests queue: `telcenter_ai_agent_requests`
- Responses queue: `telcenter_ai_agent_responses`
- These can be configured via `.env`:
  - `TELCENTER_AI_AGENT_REQUESTS_QUEUE`
  - `TELCENTER_AI_AGENT_RESPONSES_QUEUE`
