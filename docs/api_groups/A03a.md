# A03 Group

This is the group of APIs between
the [Core's Consultation Service](../services/core/S01_Consultation_Service.md)
and [Core's Metrics Service](../services/core/S08_Metrics_Service.md).


## A03a - Events API

This API is based on RabbitMQ using queue: `s01_events_queue`

In this API, S01 publishes events to this queue, and S08 subscribes to update metrics in real-time.

The API has 3 events.

### A03a Event: `conversation_start`

Triggered when a new conversation starts.

Event body format:

```json
{
  "event_type": "conversation_start",
  "params": {
    "conversation_id": "1001",
    "customer_id": "50023",
    "partner_id": "abcdef",
    "created_at": "2025-12-08T15:21:00Z"
  },
  "id": "1234"
}
```

### A03a Event: `conversation_status_update`

Triggered when a conversation status changes.

Event body format:

```json
{
  "event_type": "conversation_status_update",
  "params": {
    "conversation_id": "1001",
    "partner_id": "abcdef",
    "old_status": "AI_AGENT_TEXTING",
    "new_status": "FORWARDING",
    "updated_at": "2025-12-08T15:25:00Z"
  },
  "id": "12345"
}
```

**Possible status values:**
- `AI_AGENT_TEXTING`: AI agent texting
- `AI_AGENT_CALLING`: AI agent on phone call
- `FORWARDING`: Being forwarded to human
- `HUMAN_AGENT_TEXTING`: Human agent texting
- `HUMAN_AGENT_CALLING`: Human agent on phone call


### A03a Event: `conversation_customer_satisfaction_changed`

Triggered when customer provides or changes satisfaction rating.

Event body format:

```json
{
  "event_type": "conversation_customer_satisfaction_changed",
  "params": {
    "conversation_id": "1001",
    "partner_id": "abcdef",
    "old_satisfaction": 1,
    "new_satisfaction": 5,
    "updated_at": "2025-12-08T15:30:00Z"
  },
  "id": "12346"
}
```

**Satisfaction values:** 1, 2, 3, 4, 5 

### A03a Event: `conversation_forwarded`

Triggered when a conversation is forwarded to a partner (human agent).

Event body format:

```json
{
  "event_type": "conversation_forwarded",
  "params": {
    "conversation_id": "1001",
    "partner_id": "abcdef",
  },
  "id": "12347"
}
```
