# H30 Group

This is the group of HTTP APIs between
the **Partner Portal**
and [Partner's Metrics Service](../services/partner/S14_Partner_Metrics_Service.md).

This API consists of 3 endpoints.

## Regarding HTTP API(s)

Endpoints denoted with "AUTH"
means that it must be authenticated
using JWT.

[How to verify JWTs](../auth/VERIFY.md)

## H30

This API is based on HTTP (RESTful).

In this API, the Partner Portal calls Partner's Metrics Service
to retrieve various metrics data specific to the partner
that the Partner Portal user belongs to.

The API has 3 endpoints serving partner-specific metrics data:
1. Total number of conversations (overall, texting conversations, calling conversations)
2. Customer satisfaction rate
3. Consultation offload rate for this Partner

### H30.1 Endpoint: `GET AUTH /api/v1/partner/metrics/conversations`

This endpoint is called by Partner Portal to retrieve conversation statistics for this partner, including total conversations, texting conversations, and calling conversations.

Request headers:
```
Authorization: Bearer <jwt_token>
```

Query parameters: 
- `from_date` (optional): Start date for conversation statistics (ISO 8601 format)
- `to_date` (optional): End date for conversation statistics (ISO 8601 format)

Response format (HTTP 200):

```json
{
  "status": "success",
  "total_conversations": 1850,
  "texting_conversations": 1240,
  "calling_conversations": 582,
  "from_date": "2025-01-01T00:00:00Z",
  "to_date": "2025-12-12T23:59:59Z"
}
```


### H30.2 Endpoint: `GET AUTH /api/v1/partner/metrics/satisfaction-rate`

This endpoint is called by Partner Portal to retrieve the distribution of consultation sessions by customer satisfaction rating (1-5 stars).

Request headers:
```
Authorization: Bearer <jwt_token>
```

Query parameters:
- `from_date` (optional): Start date for consultation statistics (ISO 8601 format)
- `to_date` (optional): End date for consultation statistics (ISO 8601 format)

Response format (HTTP 200):

```json
{
  "status": "success",
  "total_conversations": 1000,
  "satisfaction_distribution": {
        "satisfaction_1": 10,
        "satisfaction_2": 25,
        "satisfaction_3": 150,
        "satisfaction_4": 400,
        "satisfaction_5": 415
  },
  "average_rating": 4.19,
  "from_date": "2025-01-01T00:00:00Z",
  "to_date": "2025-12-12T23:59:59Z"
}
```

### H30.3 Endpoint: `GET AUTH /api/v1/partner/metrics/offload-rate`

This endpoint is called by Partner Portal to retrieve the consultation offload rate for this specific Partner (the rate at which consultations are forwarded from AI to Partner staff).

Request headers:
```
Authorization: Bearer <jwt_token>
```

Query parameters:
- `from_date` (optional): Start date for consultation statistics (ISO 8601 format)
- `to_date` (optional): End date for consultation statistics (ISO 8601 format)

Response format (HTTP 200):

```json
{
  "status": "success",
  "total_conversations": 12840,
  "ai_failed_conversation": 9770,
  "offloaded_conversations": 28650,
  "offload_rate_percentage": 74.57,
  "from_date": "2025-01-01T00:00:00Z",
  "to_date": "2025-12-12T23:59:59Z"
}
```

## Error Responses

The following error responses apply to all endpoints:

**HTTP 400 Bad Request**
```json
{
  "status": "error",
  "error_code": "INVALID_PARAMETERS",
  "message": "Invalid query parameters",
  "details": "from_date must be before to_date"
}
```

**HTTP 401 Unauthorized**
```json
{
  "status": "error",
  "error_code": "UNAUTHORIZED",
  "message": "Authentication token is invalid or expired"
}
```

**HTTP 403 Forbidden**
```json
{
  "status": "error",
  "error_code": "FORBIDDEN",
  "message": "User does not have permission to view metrics"
}
```

**HTTP 500 Internal Server Error**
```json
{
  "status": "error",
  "error_code": "INTERNAL_ERROR",
  "message": "An internal server error occurred while retrieving metrics"
}
```

## Configuration

Base API URL (for frontend) should be configurable via `.env`:
- `PARTNER_METRICS_SERVICE_URL` (e.g., `http://localhost:5014`)
