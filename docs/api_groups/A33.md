# A33 Group

This is the group of APIs between
the [Partner's Knowledge Update Service](../services/partner/S12_Partner_Knowledge_Update_Service.md)
and [Partner's Local Knowledge Service](../services/partner/S11_Partner_Local_Knowledge_Service.md).

**Direction:** S12 → S11

**Type:** Event (fire-and-forget, no response needed)

This API consists of 1 API.

## A33

This API is based on RabbitMQ.

The API has 1 event.

### A33 Event: `process_update_request`

This event is emitted by S12 to notify S11 that a new knowledge update request has been created and needs processing.

Event body format:

```json
{
  "event": "process_update_request",
  "data": {
    "update_id": "draft_upd_1234",
    "update_name": "Cập nhật gói cước Q4 2025",
    "update_type": "new_entries",
    "seaweed_file_id": "3,01234567"
  }
}
```

## Queue Configuration

- Event Queue: `partner_update_events`

Configurable via `.env`:
- `PARTNER_UPDATE_EVENT_QUEUE`

## Notes

- S12 emits this event when receiving a create update request from H29
- S11 consumes the event and forwards to S15 (A32) for AI processing
