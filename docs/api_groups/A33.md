# A33 Group

This is the group of APIs between
the [S12 - Partner's Knowledge Update Service](../services/partner/S12_Partner_Knowledge_Update_Service.md)
and [S11 - Partner's Local Knowledge Service](../services/partner/S11_Partner_Local_Knowledge_Service.md).

This API consists of 1 API.

## A33

**Direction:** S12 → S11

This API is based on RabbitMQ.

The API has 1 method.

### A33 Method: `snapshot`

S12 calls this method to obtain a snapshot
of the current content of S11's database
(including only the packages and FAQs data).

Request body format:

```json
{
  "method": "snapshot",
  "params": {},
  "id": "1234"
}
```

Response body format:

```json
{
    "id": "the corresponding request id",
    "result": {
        "status": "success or error",
        "content": "the return value of the called method"
    }
}
```

On success, the content's format would be:

```ts
{
  "seaweed_file_id": string
}
```

On failure (`status == 'error'`), the content would
reflect what is going on. If the failure is
caused by some `Exception`, the content should
be `str(e)` with `e` being the `Exception` instance
that was the culprit.

## Queue Configuration

- Request Queue: `snapshot_requests`
- Response Queue: `snapshot_responses`

Configurable via `.env`:

- `SNAPSHOT_REQUESTS_QUEUE_NAME`
- `SNAPSHOT_RESPONSES_QUEUE_NAME`
