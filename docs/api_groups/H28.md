# H28 Group

This is the group of HTTP APIs between
the **Partner Portal**
and [Partner's Local Knowledge Service](../services/partner/S11_Partner_Local_Knowledge_Service.md).

This API consists of 1 API.

## H28

This API is based on HTTP (RESTful).

The API has 2 endpoints serving 2 main tasks:
1. Import local knowledge file
2. Add consultation service package

### H28 Endpoint: `POST /api/v1/local-knowledge/import-file`

This endpoint is called by Partner Portal to import a file containing telecom service knowledge into the local partner knowledge database.

Request headers:
```
Authorization: Bearer <jwt_token>
Content-Type: multipart/form-data
```

Request body (multipart form data):

Metadata format:
```json
{
  "source": "Viettel",
  "description": "Dữ liệu gói cước Q4 2025",
  "import_type": "local_only",
  "notes": "Nhập kiến thức vào database local để tư vấn"
}
```
Request body (multipart form data):

- `file`: The file to upload (binary) — recommended types: `pdf`.
- `metadata`: JSON string with metadata about the import.

Metadata format:

```json
{
  "partner_id": "viettel_partner_001",
  "uploaded_by": "employee_123",
  "description": "Local knowledge update package",
  "package_type": "service_package",
  "record_count": 50
}
```

Behavior and SeaweedFS storage:
- On receiving the multipart upload, H28 MUST store the uploaded file into SeaweedFS and return the SeaweedFS reference in the immediate response.
- If the upload is large, H28 may return `202 Accepted` with a `task_id` while background processing completes; however the SeaweedFS `file_id` should still be returned when the file is successfully stored.

Response format (HTTP 202 Accepted or 201 Created when processed immediately):

```json
{
  "status": "processing",
  "task_id": "task_abc123",
  "message": "File received and queued for processing.",
  "file_reference": {
    "storage": "seaweed",
    "file_id": "<seaweed_fid_or_file_id>",
    "file_url": "https://seaweed.master:9333/<file_id>",
    "file_size": 123456
  }
}
```

Integration notes:
- H28 MUST use the configured SeaweedFS master (`SEAWEED_MASTER_URL`) to upload the file and obtain the file id/fid.
- H28 should include the returned `file_reference.file_id` when it sends `A32` / `process_file_import` to S15 so S15 can access the file directly.

SeaweedFS configuration (set via `.env`):
- `SEAWEED_MASTER_URL` (e.g. `http://seaweed-master:9333`) — HTTP endpoint for master server.
- `SEAWEED_PUBLIC_URL` (optional) — public-facing base URL for files, used to form `file_url`.
- `SEAWEED_COLLECTION` (optional) — collection name to store files under.
- `SEAWEED_REPLICATION` (optional) — replication parameter for SeaweedFS `upload` call.

Import types:
- `"local_only"` - Import only to local database, not sent to Core
- `"for_sync"` - Import and prepare for sync to Core later

Response format (HTTP 202 Accepted):

```json
{
  "status": "processing",
  "import_id": "local_import_1234",
  "message": "File đang được xử lý để import vào kiến thức local",
  "estimated_processing_time_seconds": 30,
  "status_url": "/api/v1/local-knowledge/import-status/local_import_1234"
}
```

Response format (HTTP 200) - Check status endpoint:

```json
{
  "status": "completed",
  "import_id": "local_import_1234",
  "completed_at": "2025-12-08T10:30:45Z",
  "result": {
    "imported_count": 48,
    "failed_count": 2,
    "confidence_score": 0.92,
    "warnings": [
      "Dòng 15: Thiếu mã dịch vụ, bỏ qua",
      "Dòng 23: Định dạng giá không rõ ràng"
    ],
    "message": "Đã import thành công 48 gói cước vào kiến thức local"
  }
}
```

Error responses:

**HTTP 400 Bad Request** - Invalid file
```json
{
  "status": "error",
  "error_code": "INVALID_FILE",
  "message": "Định dạng file không được hỗ trợ",
  "details": "Chỉ hỗ trợ file .xlsx, .xls, .pdf, và .docx"
}
```

**HTTP 413 Payload Too Large**
```json
{
  "status": "error",
  "error_code": "FILE_TOO_LARGE",
  "message": "Kích thước file vượt quá giới hạn 50MB"
}
```

**HTTP 401 Unauthorized**
```json
{
  "status": "error",
  "error_code": "UNAUTHORIZED",
  "message": "Token xác thực không hợp lệ hoặc đã hết hạn"
}
```

### H28 Endpoint: `POST /api/v1/local-knowledge/add-package`

This endpoint is called by Partner Portal to manually add a consultation service package to the local knowledge database.

Request headers:
```
Authorization: Bearer <jwt_token>
Content-Type: application/json
```

Request body format:

```json
{
  "source": "Viettel",
  "package": {
    "Mã dịch vụ": "SD70",
    "Thời gian thanh toán": "Trả trước",
    "Các dịch vụ tiên quyết": "",
    "Giá (VNĐ)": 70000,
    "Chu kỳ (ngày)": 30,
    "4G tốc độ tiêu chuẩn/ngày": 1,
    "4G tốc độ cao/ngày": 0,
    "4G tốc độ tiêu chuẩn/chu kỳ": 30,
    "4G tốc độ cao/chu kỳ": 0,
    "Gọi nội mạng": "",
    "Gọi ngoại mạng": "",
    "Tin nhắn": "",
    "Chi tiết": "Gói cước data 4G tốc độ tiêu chuẩn",
    "Tự động gia hạn": "Có",
    "Cú pháp đăng ký": "SD70 DK8 gửi 290"
  },
  "add_type": "local_only",
  "notes": "Thêm gói cước mới cho tư vấn viên"
}
```

Add types:
- `"local_only"` - Add only to local database, not sent to Core
- `"for_sync"` - Add and prepare for sync to Core later

Response format (HTTP 201 Created):

```json
{
  "status": "success",
  "package_id": "local_pkg_5678",
  "message": "Đã thêm gói cước vào kiến thức local thành công",
  "package": {
    "Mã dịch vụ": "SD70",
    "Thời gian thanh toán": "Trả trước",
    "Giá (VNĐ)": 70000,
    "Chu kỳ (ngày)": 30,
    "4G tốc độ tiêu chuẩn/ngày": 1,
    "4G tốc độ cao/ngày": 0,
    "4G tốc độ tiêu chuẩn/chu kỳ": 30,
    "4G tốc độ cao/chu kỳ": 0,
    "Gọi nội mạng": "",
    "Gọi ngoại mạng": "",
    "Tin nhắn": "",
    "Chi tiết": "Gói cước data 4G tốc độ tiêu chuẩn",
    "Tự động gia hạn": "Có",
    "Cú pháp đăng ký": "SD70 DK8 gửi 290",
    "_created_at": "2025-12-08T10:35:00Z",
    "_created_by": "employee_123"
  }
}
```

Error responses:

**HTTP 400 Bad Request** - Invalid data
```json
{
  "status": "error",
  "error_code": "INVALID_PACKAGE_DATA",
  "message": "Dữ liệu gói cước không hợp lệ",
  "details": {
    "missing_fields": ["Mã dịch vụ", "Giá (VNĐ)"],
    "invalid_fields": ["Chu kỳ (ngày)"]
  }
}
```

**HTTP 409 Conflict** - Duplicate package
```json
{
  "status": "error",
  "error_code": "DUPLICATE_PACKAGE",
  "message": "Mã dịch vụ đã tồn tại trong kiến thức local",
  "existing_package_id": "local_pkg_1234"
}
```

**HTTP 401 Unauthorized**
```json
{
  "status": "error",
  "error_code": "UNAUTHORIZED",
  "message": "Token xác thực không hợp lệ hoặc đã hết hạn"
}
```

**HTTP 403 Forbidden**
```json
{
  "status": "error",
  "error_code": "FORBIDDEN",
  "message": "Người dùng không có quyền thêm gói cước"
}
```

## Configuration

Base URL should be configurable via `.env`:
- `PARTNER_LOCAL_KNOWLEDGE_SERVICE_URL` (e.g., `http://localhost:7011`)

## Notes

- All requests require JWT authentication with partner employee credentials
- Rate limiting: 60 requests per minute per user
- Supported file types for import:  .pdf
- Maximum file size: 50MB
- Package data validation follows Vietnamese telecom service standards
- CORS enabled for Partner Portal domain
- File processing is asynchronous - use status endpoint to check progress
- Local knowledge is immediately available for consultation after adding
- Data added with `"local_only"` type will NOT be synced to Telcenter Core
- Data added with `"for_sync"` type can be submitted to Core later via H29 endpoints
