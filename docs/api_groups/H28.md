# H28 Group

This is the group of APIs between the **Partner Portal** and **S11 Partner Local Knowledge Service**

This API consists of **1** API(s).

## Regarding HTTP API(s)

Endpoints denoted with "AUTH"
means that it must be authenticated
using JWT.

[How to verify JWTs](../auth/VERIFY.md)

## H28

**Direction:** Partner Portal(Frontend) → S11

This API is based on **HTTP**.

This API supports the following use cases:

- TP-07: Thêm gói cước
- TP-08: Sửa gói cước
- TP-09: Xóa gói cước
- TP-10: Thêm câu hỏi thường gặp (FAQ)
- TP-11: Sửa FAQ
- TP-12: Xóa FAQ
- TP-13a: Tải file dữ liệu kiến thức viễn thông lên hệ thống (import file).
- TP-13b: Xem trạng thái xử lý file dữ liệu kiến thức viễn thông đã tải lên (danh sách các file imports).
- TP-13c: Xem chi tiết một file import (bao gồm các gói cước được trích xuất từ file, nếu trích xuất thành công).
- TP-13d: Sửa thông tin các gói cước được trích xuất từ file import (tại trang chi tiết file import). Bao gồm sửa, thêm, và xóa các gói cước đó.
- TP-13e: Approve một file import - tức là chấp nhận các gói cước được trích xuất từ file import (tại trang chi tiết file import) để đưa vào cơ sở dữ liệu chính thức của hệ thống.
- TP-13f: Reject một file import.

        "4G tốc độ cao/ngày": number,
        "4G tốc độ tiêu chuẩn/chu kỳ": number,
        "4G tốc độ cao/chu kỳ": number,

### Endpoint `POST AUTH /api/v1/local-knowledge/file-imports`

This endpoint corresponds to TP-13a.

Import a PDF file containing bulk knowledge data (packages and FAQs).

Request body (multipart/form-data):

```
POST /api/v1/local-knowledge/file-import
Content-Type: multipart/form-data
file: <binary_file_data>
metadata: { // JSON string
    "file_name": string // original file name
}
```

Response status: 202 Accepted

Response body:

```ts
{
    "content": {
        "id": string, // import task ID, corresponding to `file_imports` collection of S11
        "message": "File import initiated successfully"
    }
}
```

### Endpoint: `PATCH AUTH /api/v1/local-knowledge/file-imports/{id}/packages`

This endpoint corresponds to TP-13d.

Edit the extracted packages of a file import,
including adding, updating, and deleting packages
(that is, the frontend will send the full list of packages
after the user has made changes; the frontend is
responsible for displaying add/edit/delete buttons
for those packages).

Request URL parameter:

- `id`: The ID of the file import to edit packages for

Request body:

```ts
{
    "packages": Array<{
        "Mã dịch vụ": string,
        "Thời gian thanh toán": string,
        "Các dịch vụ tiên quyết": string,
        // ... other package fields as above
        // NOTE: No `id` field!
    }>
}
```

Response body:

```ts
{
    "content": {
        "id": string, // import task ID
        "message": "Extracted packages updated successfully"
    }
}
```

## Configuration

- Base API URL should be configurable via `.env`:
    `PARTNER_LOCAL_KNOWLEDGE_SERVICE_URL` (e.g., `http://localhost:7011`)
- Implement CORS to allow requests from Partner Portal frontend
    (for that base URL).

- SeaweedFS configuration:
  - `SEAWEED_MASTER_URL` (e.g., `http://seaweed-master:9333`)
  - `SEAWEED_PUBLIC_URL` (optional, for public file access)

## Notes

- All requests require JWT authentication with partner employee credentials
- Rate limiting: 60 requests per minute per user
- Supported file types for import: .pdf
- Maximum file size: 50MB
- After CRUD operations (NOT file imports), the changes are applied
    directly to the Local knowledge DB of S11.
- In contrast, file imports go through an approval process:
    after a file is imported and processed, the extracted packages/FAQs
    are stored temporarily and the partner employee must approve
    or reject them before they are applied to the main database.
    Also, if the file import fails, the partner employee should be
    informed of the error message, and will not be able to approve/reject
    the import.
